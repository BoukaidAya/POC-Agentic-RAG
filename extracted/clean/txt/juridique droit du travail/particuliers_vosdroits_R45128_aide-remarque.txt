Besoin d’aide ? Une remarque ?
Votre question
Ma question concerne Requête aux fins de saisine du conseil de prud'hommes (CPH) par un salarié
(https://www.service-public.gouv.fr/particuliers/vosdroits/R45128)
Vos questions les plus fréquentes sur le sujet
A qui dois-je envoyer le document ?
Après avoir rempli, téléchargé, imprimé et signé votre document, vous devez l’adresser vous-même à l’organisme en
charge de l’instruction de votre demande.
Les conditions d’envoi du document sont précisées dans les informations générales ou la notice jointes au formulaire.
Je ne retrouve pas le brouillon de ma démarche. Est-ce normal ?
Lorsque vous remplissez votre document en ligne, aucun brouillon n’est conservé.
Ainsi, si vous quittez la page que vous étiez en train de rédiger, vous perdez les informations remplies. Vous devez le
remplir en une seule fois, puis télécharger votre document, l’imprimer et le signer.
Pensez à récupérer toutes les informations dont vous avez besoin avant de remplir votre document.
Un code d’erreur s’affiche pendant que je remplis mon document. Que faire ?
Lorsque vous remplissez votre document, un numéro d’erreur s’affiche, en général, en cas de mauvaise saisie d’un
champ du document (ajout par erreur d’un caractère spécial, par exemple).
Pour résoudre ce problème, vous pouvez essayer de remplir à nouveau votre document, puis le télécharger. Privilégiez
si possible de remplir le document à partir d’un ordinateur.
Je ne parviens pas à télécharger le document que j’ai rempli en ligne. Que faire ?
Le lien pour télécharger votre document s’affiche, sur certaines pages, uniquement après avoir rempli tous les champs
obligatoires. Si le lien n’apparait toujours pas après les avoir remplis, nous vous invitons à remplir, puis télécharger
à nouveau votre document, de préférence à partir d’un ordinateur.
Si vous étiez déjà en train de remplir le document via à un ordinateur, vous pouvez recommencer après avoir :
Soit vidé le cache de votre ordinateur,
Soit changé de navigateur ou utilisé une fenêtre de navigation privée,
Soit recommencé à partir d’un autre support (ordinateur, smartphone, tablette).
Je ne retrouve pas le document que j’ai téléchargé. Que faire ?

Aucun brouillon du document que vous avez rempli n’est conservé. Si vous ne retrouvez pas le document, nous vous
invitons à le remplir, puis à le télécharger à nouveau, de préférence à partir d’un ordinateur.
Comment faire pour signer le document ?
Lorsque vous remplissez votre document, vous ne pouvez pas le signer directement en ligne. Vous devez d’abord le
télécharger, l’imprimer, puis le signer à la main.
Je souhaite corriger mon document. Comment faire ?
Si vous avez besoin de modifier une information dans votre document, vous devrez le rédiger à nouveau depuis le
début.
Attention : si vous avez déjà transmis le document à l’organisme chargé d’instruire votre demande, nous vous invitons
à le contacter directement pour lui signaler la modification à apporter.
Je n’ai finalement plus besoin de remplir le document. Puis-je annuler ma demande ?
Le document que vous avez rempli, téléchargé, imprimé et signé doit être ajouté au dossier que vous constituez pour
votre démarche. Ainsi, si vous n’avez pas encore transmis votre dossier à l’organisme concerné, vous n’avez rien à faire.
A l’inverse, si vous l’avez déjà transmis, contactez directement l’organisme concerné pour lui signifier que vous
souhaitez annuler votre demande.
